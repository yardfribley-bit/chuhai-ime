REAL CASES

三种你会碰到的情况。

下面每句都是可以直接试的原文。
云服务要先在设置里打开。

01

网页里看不懂的英文

用鼠标选中那几个词。Mac 按 Control Option T，Windows 按 Ctrl Alt T。选区旁边浮出「译」。

Windows 桌面版 (Claude Desktop)
译　Claude 桌面版
02

复制来的一整段英文

贴进文本框，光标放在这段末尾，输入半角 //。有空格的句子才会触发，单个单词和网址不会。

We are fixing a vulnerability.//
我们正在修复一个漏洞。
03

自己打的中文

五笔 inim 选「漏洞」，或拼音 loudong。整段打完后在末尾输入 //，译成「通用 → 整句翻译」里选的语言。

我们正在修复一个漏洞。//
We are fixing a vulnerability.

AFTER THE PREVIEW

看清译文，再决定要不要换。

01

小窗先写「翻译中…」

云端还在返回时，小窗左边是「译」，底下写着 Esc 取消。不要移动光标。

02

回车才替换

中文或英文出现后，按回车、空格或 1 替换选中的原文。按 Esc 留着原来的字。

↵ 替换 · Esc 保留
03

产品名可以留着

Claude Desktop、Hyper-V、Vmmem 这类名字多半原样保留。想要整句中文，就把旁边的中文一起选上。

A FEW THINGS TO KNOW

开始之前，你可能想知道。

输入和翻译都必须联网吗？

基础中文输入使用本地词库。整句翻译需要联网，并配置兼容的接口、模型和个人 API 密钥，费用由你选择的服务商收取。安装包不包含他人的密钥。

哪些内容会发送给翻译服务？

主动触发整句翻译时，待译中文段落会发送到你配置的服务；启用云联想后，组句上下文也会发送。密码和私密输入框不触发云请求。今日词本保存在本机。

可以用于网络安全等专业内容吗？

可以使用整句翻译辅助表达；专业术语准确度取决于所配置的模型和上下文。请在发送前检查英文预览，尤其是技术名称与事实。
