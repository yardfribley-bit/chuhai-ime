A FEW THINGS TO KNOW

开始之前，你可能想知道。

输入和翻译都必须联网吗？

基础中文输入使用本地词库。整句翻译需要联网，并配置兼容的接口、模型和个人 API 密钥，费用由你选择的服务商收取。安装包不包含他人的密钥。

哪些内容会发送给翻译服务？

主动触发整句翻译时，待译中文段落会发送到你配置的服务；启用云联想后，组句上下文也会发送。密码和私密输入框不触发云请求。今日词本保存在本机。

可以用于网络安全等专业内容吗？

可以使用整句翻译辅助表达；专业术语准确度取决于所配置的模型和上下文。请在发送前检查英文预览，尤其是技术名称与事实。

项目开源吗？在哪里反馈问题？

出海舰基于 Qingjian 修改，遵循 GPL-3.0-or-later，保留原作者和数据来源声明。查看源码，或在 GitHub Issues 描述系统版本、应用和复现步骤。
