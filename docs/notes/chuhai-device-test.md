# 出海舰设备验收

编译通过不代表输入法在 X 等应用里可用。请逐项记录设备、系统版本、应用版本和结果。

## Android

安装 `target/android/出海舰-0.1.0-test.apk`，在系统键盘设置启用出海舰，然后切换到出海舰。测试包支持 Android 8+ 的 ARM64 手机和 x86_64 模拟器。

1. 在普通文本框选择拼音，输入 `nihao` 并选“你好”；选择五笔86，输入 `wq` 并选择候选；混输也应有中文候选。
2. 在浏览器、X 和聊天应用完成一段中文选词，在光标末尾输入 `//`；配置云翻译后应出现英文预览，按回车替换。
3. 翻译期间取消、切换应用、移动光标或改动原文，原文应保留，不替换其他位置；联网失败不删除原文。
4. 英文、URL、代码中的 `//` 应正常输入，不误触翻译；密码和 PIN 框不发送翻译请求。
5. 成功接受翻译后主动打开“设置 → 今日学词”；取消的翻译不计入词本，同一词不重复新增。标记掌握后复习列表更新。

“设置”可填写兼容 OpenAI Chat Completions 的 HTTPS 地址、模型与密钥。测试签名用于本地验收，正式分发需要发布签名。

## Windows

先准备 Rust MSVC 工具链、Visual Studio C++ 桌面开发组件、Windows SDK 和 Inno Setup 7。解压源码包后，在源码根目录的 PowerShell 执行：

```powershell
rustup target add i686-pc-windows-msvc
.\apps\windows\installer\build.ps1
```

安装包输出到 `target\installer\chuhai-<版本>-windows-x86_64-setup.exe`。普通测试不要加 `-Sign`。安装后注销登录，再在系统输入法列表选择出海舰。

在记事本和 X 浏览器分别执行 Android 清单中的输入与翻译检查，再检查 32 位应用。今日词本通过设置的“统计 → 今日学词”打开，目前桌面复习页只读。配置和密钥应只留在测试电脑，不加入源码包。

## macOS

新版构建号236；已可用基线235保留回退副本。安装后检查菜单显示出海舰，五笔86配置保留，再测试与前述相同的 `//`、取消、失焦和光标变化情况。今日学词从输入法菜单主动打开。系统管理员安装对话框需要本机用户完成。
