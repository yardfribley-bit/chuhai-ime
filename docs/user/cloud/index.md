云联想缺省关闭。打开后，输入拼音时会将当前拼音与光标附近的文字发送给**用户自行填写的** AI 服务商，换回候选词与整句补全。
数据直接从本机发送到服务商，不经过青简；密码框与应用声明为私密的输入框中不发送。

## 开启

Mac、Windows 的「云服务」页和 Android 的「设置 → 整句云翻译」采用相同流程：

1. 搜索或选择接入服务：OpenRouter、DeepSeek 官方，或自定义中转。
2. 获取模型列表，按熟悉的名称搜索并选择；程序保存完整模型 ID。OpenRouter 选中后自动获取，DeepSeek 官方及需要认证的中转需先粘贴密钥。
3. 粘贴所选接入服务的密钥，点击「连接并启用」。验证会发送一条固定消息，可能产生少量接口费用；连接成功后启用，失败保留已填写内容。

官方服务的接口地址自动填写。自定义中转只需填写服务商提供的 HTTPS 地址；不提供模型列表时可手动填写完整模型 ID。DeepSeek 官方和 OpenRouter 上的 DeepSeek 使用各自平台的密钥，不能互换。切换接入服务时旧服务暂停，需要填写新服务的密钥，防止把密钥发给不同服务。

密钥只保存在本机。桌面端启用云服务后会开启联想，发送光标附近的上下文；Android 仅在主动触发翻译时发送段落。可随时暂停云服务。Mac 菜单栏模式名称旁带 ☁︎ 表示云服务已开启。

输入法由系统启动，不读取终端中设置的代理；若需通过代理访问服务商，请在系统设置中设置系统代理，或使用 TUN 模式的代理工具。

发送的内容：所敲字母、本机的切分、光标前后各几十个字的上下文、本机给出的候选。详见 [数据与日志](../help/data-and-logs.md#云联想发什么)。

## 云端候选词

输入拼音时停顿 300 毫秒后，云端给出的词补入候选第一页**末尾**两格（「云服务」页可调为 0 至 4），带云朵标记，数字键正常选择，上屏消耗整段拼音。

- 前面的本地候选位置不变，`Space` 上屏的仍是本地首选。
- 未返回、无结果、超时均不改变显示，不预留、不画占位。
- 选中词库中没有的云端词会记为用户词（按所敲的读音记录，不按云端给出的读音），下次本地直接给出。
- 云端可纠错：`zhgdoima` 同样可得到「这个东西吗」。
- 只敲声母（简拼，如 `fhyq`）时云端不再给词，只给整句补全——按声母凑出来的词大多不是真词。

## 整句补全

同一次请求还返回一条整句：以当前输入开头的完整说法（`suoyiwoxiangq` → 所以我想去吃饭），带云朵显示在拼音右侧。
`Tab` 接受，继续输入则替换。有应用上下文时接着上下文续写。

## 译词自动补充

随包释义表中没有译词的词，在输出后会单独向云端询问一次（只发送该词），返回的译词存入本机的个人释义表，下次候选旁即有显示。
关闭云服务后不再发送任何请求。

## 不联想的情况

上屏之后不联想；英文模式、以 `v` 开头的算式不联想；密码框中不联想。

Windows 中可先在搜索框输入模型名称，再从下方列表选择完整模型；选择后搜索条件会保留，方便核对。
