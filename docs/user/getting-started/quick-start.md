## 第一次使用

在系统输入法列表中选择「出海舰」。macOS 输入法菜单中可打开「使用指南…」和「偏好设置…」。

输入中文前，确认菜单栏显示「中」。macOS 使用 `Caps Lock` 切换中英文，显示「英」时输入英文，再按一次切回中文。单击 `Shift` 目前不切换模式。

五笔86示例：输入 `inim`，选择「漏洞」。拼音示例：输入 `loudong`，选择「漏洞」。按 `Space` 选择首选候选，或按数字选择对应候选。输入方案可在「偏好设置 → 通用」中设置。

## 配置整句翻译

1. 打开「偏好设置 → 云服务」，启用云服务。
2. 填写服务商的兼容接口地址、模型名称和 API 密钥，每个输入框按 `Enter` 保存。
3. 点击「测试连接」，窗口底部显示测试结果。

使用 OpenRouter 时，接口地址为 `https://openrouter.ai/api/v1`，模型填写服务商提供的完整模型标识，例如 `deepseek/deepseek-v3.2`。密钥需有可用额度；账户余额和单个密钥的限额可能不同。密钥只应填写在本机设置中，不应发布到 GitHub 或聊天记录。

## 如何触发翻译

1. 完成一段中文输入，先选择候选，使中文出现在应用文本框中。
2. 将光标放在当前段落末尾，连续输入两个半角斜杠 `//`。
3. 第一个 `/` 正常输入，第二个 `/` 触发整句英文翻译。等待候选窗口出现英文预览。
4. 按 `Enter` 确认，英文替换当前段落及触发斜杠。

示例：输入 `我们正在修复一个漏洞。//`，等待英文预览，按 `Enter` 使用译文。

翻译只处理光标前的当前段落，不处理整篇文章。长内容应分段输入。等待时不要移动光标、修改原文或切换应用。

## 如何取消与排查失败

按 `Esc` 取消，保留中文原文和第一个 `/`。失败或超时也保留原文。

若没有触发，确认中文已完成选词、使用了半角 `//`、光标位于段落末尾、云服务已启用，并检查应用是否支持读取文本。密码及私密输入框不触发云翻译。

若提示翻译失败，在「云服务」中点击「测试连接」，检查接口地址、模型、密钥限额与网络。即使有余额，请求也可能因网络或服务商响应较慢而超时。

## 今日学词

成功接受英文译文后，从输入法菜单打开「今日学词…」，查看今天首次遇到的英文单词或短语、中文含义和原句。取消的译文不计入词本，相同词条不重复新增。复习只在主动打开时展示。

今日词本保存在本机。云翻译会把待译原文发给你配置的服务商，费用由该服务商收取，出海舰没有自建翻译服务器。
